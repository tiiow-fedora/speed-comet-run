# ASSETS

Every asset in the game is original: generated by scripts in this repo or built from Roblox primitives at runtime. **No Creator Store / third-party assets are used.**

## Meshes (Blender, `blender/props.py`, uploaded via Open Cloud Assets API as Model/FBX)
| Name | Source | Asset ID | Moderation |
|---|---|---|---|
| Rock1 | `blender/props.py` noise-displaced icosphere, 80 faces | 72645655828561 | Approved |
| Rock2 | same, different seed | 121471108529248 | Approved |
| Rock3 | same, subdivision 1, 20 faces | 79693074857712 | Approved |
| Crystal | `blender/props.py` three hexagonal shards, 39 faces | 103157670483871 | Approved |

Loaded at server start by `src/server/PropLoader.luau` (InsertService:LoadAsset; asset owner = place owner). If loading fails, MapBuilder falls back to primitive parts.

## Built-in Roblox content (engine assets, not marketplace)
- `rbxasset://textures/particles/sparkles_main.dds`: engine particle texture (ships with the client)
- Fonts: FredokaOne, GothamBold (engine fonts)
